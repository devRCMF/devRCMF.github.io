Como doar

  1. Escolha a campanha ou deixe a doação livre para onde houver mais necessidade.
  2. Pague por Pix usando a chave do CNPJ ou por transferência bancária.
  3. Envie o comprovante para o e-mail de contato, com o seu nome, para receber o recibo.
  4. Cadastre-se como apoiador para receber o relatório trimestral de aplicação dos recursos.

Dúvidas frequentes

A doação pode ser deduzida do imposto de renda?

Doações de pessoa física a associações sem o título de utilidade pública federal não geram dedução. Consulte seu contador antes de contar com esse benefício.

Posso escolher para qual projeto vai o valor?

Sim. Informe o projeto no comprovante. Sem indicação, a diretoria direciona o recurso para a campanha com menor percentual atingido.

Menores de idade podem ser voluntários?

A partir de 16 anos, com autorização assinada por um responsável legal.
